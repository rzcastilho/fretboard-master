# 10 — Glossary

## 1. Instrument terms

| Term | Definition |
|---|---|
| **Fretboard / neck** | The part of the instrument that holds the strings and the frets; in the application, the component that represents it |
| **Nut** | The piece at the start of the neck on which the strings rest. It marks fret 0 |
| **Fret** | Each metal strip that divides the neck; also the position just behind that strip. Fret *n* is the position played by pressing behind strip *n*. Fret 0 = open string |
| **Open string** | A string played without pressing any fret |
| **String numbering** | 1 is the highest; 6 (or 7) is the lowest |
| **Inlay / position marker** | The reference dots on the neck, at frets 3, 5, 7, 9, 12, and so on |
| **Tuning** | The pitches of the open strings |
| **Standard tuning** | E A D G B E, from string 6 to string 1 |
| **Compatible tuning** | A tuning in which the CAGED model applies (FR-2.12) |
| **Handedness** | Right-handed or left-handed; defines the direction in which the fretboard is drawn |
| **Position** | A string + fret pair |
| **Region** | A continuous stretch of frets |
| **Span** | The distance, in frets, between the fretted note closest to the nut and the one farthest from it in a shape |
| **Barre chord** | A chord in which one finger presses several strings at the same fret |

## 2. Theory terms

| Term | Definition |
|---|---|
| **Natural note** | A note without an accidental: C D E F G A B |
| **Altered note** | A note with a sharp or a flat |
| **Accidental** | Sharp (♯, raises by a semitone), flat (♭, lowers by a semitone), double sharp (𝄪), and double flat (𝄫) |
| **Semitone (half step)** | The smallest distance between two notes; on the fretboard, one fret |
| **Whole step** | Two semitones |
| **Key** | The tonal center ("in the key of G") |
| **Pitch class** | One of the twelve notes, regardless of octave |
| **Pitch** | A note in a specific octave; the exact sound |
| **Octave** | The distance between a note and the next one of the same name; twelve semitones |
| **Unison** | Two positions that produce the same pitch |
| **Enharmonic** | Two names for the same sound (C♯ and D♭) |
| **Spelling** | The name with which a note is written, among the enharmonic options |
| **Letter names** | Notation of the notes by letters: C D E F G A B |
| **Solfège names** | Notation of the notes by syllables: Do Re Mi Fa Sol La Si |
| **Interval** | The distance between two notes |
| **Root** | The note that names the triad, the chord, or the scale |
| **Third** | The note three or four semitones above the root (minor or major) |
| **Fifth** | The note six, seven, or eight semitones above the root (diminished, perfect, or augmented) |
| **Function** | The role of a note relative to the root: root, third, or fifth |
| **Degree** | The position of a note in the scale, counted from the root |
| **Triad** | A three-note chord built from stacked thirds: root, third, and fifth |
| **Quality** | The type of triad: major, minor, diminished, or augmented |
| **Root position** | A triad with the root as the lowest note |
| **Inversion** | A triad with another note in the bass: the third (1st inversion) or the fifth (2nd inversion) |
| **Close position** | A voicing in which the three notes of the triad fit within one octave |
| **String set** | Three adjacent strings on which a triad is played (for example, 3-2-1) |
| **Triad shape** | The drawing of a triad on a string set |
| **Open chord** | A chord played next to the nut, with open strings |
| **CAGED** | A model that organizes the neck into five regions, each associated with the shape of an open chord: C, A, G, E, and D |
| **CAGED shape** | Each of the five drawings; the name indicates the drawing, not the sound |
| **Occurrence** | A shape applied to a key, at one point on the neck |
| **Connection** | A note shared by two neighboring CAGED shapes |
| **Arpeggio** | The notes of the chord played one at a time; in the application, every triad note in a region |
| **Major scale** | A seven-note scale with the degrees R 2 3 4 5 6 7 |
| **Natural minor scale** | A seven-note scale with the degrees R 2 ♭3 4 5 ♭6 ♭7 |
| **Major pentatonic** | A five-note scale: R 2 3 5 6 |
| **Minor pentatonic** | A five-note scale: R ♭3 4 5 ♭7 |
| **Relative key** | The minor key and the major key that share the same notes (A minor and C major) |

## 3. Application terms

| Term | Definition |
|---|---|
| **Tool** | Each of the three study modes: Fretboard Notes, Triads, CAGED |
| **View** | What the fretboard shows at a given moment, the result of the tool state |
| **View state** | The set of choices that defines a view (DM-15) |
| **Marker** | The symbol drawn on a position |
| **Label** | The text inside the marker: name, interval, octave, or none |
| **Emphasis** | The degree of prominence of a position: highlighted, normal, dimmed, hidden |
| **Layer** | A set of notes that can be turned on over a CAGED shape |
| **Focus** | A position or a shape selected for examination |
| **Tag** | The tappable text above the fretboard that names a shape or an inversion |
| **Position card** | The panel with the data of the position in focus in the Notes tool |
| **Composition panel** | The panel with the triad formula in the Triads tool |
| **Minimap** | A miniature of the whole fretboard for navigation on narrow screens |
| **Preferences** | Choices remembered on the device (DM-14) |
| **State link** | An address that reopens a tool in the same view (DM-17) |
