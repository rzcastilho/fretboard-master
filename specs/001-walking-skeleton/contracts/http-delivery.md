# Contract: HTTP Delivery (addresses, status codes, headers)

**Feature**: `001-walking-skeleton` | Requirements: FR-001, FR-009, FR-010, FR-015, FR-016, FR-019, FR-022

The only external interface the product exposes is static HTTP delivery from Cloudflare Pages.
This contract is verified by `scripts/smoke-delivery.sh <base-url>` against every PR preview and
production deploy, and (for paths/status) by Playwright against `vite preview`.

## Addresses

| Request path | Status | Body | Notes |
|---|---|---|---|
| `/` | 200 | Prerendered home (`index.html`) | |
| `/notes` | 200 | Prerendered Fretboard Notes (`notes.html`) | |
| `/triads` | 200 | Prerendered Triads (`triads.html`) | |
| `/about` | 200 | Prerendered About (`about.html`) | |
| `/notes/`, `/triads/`, `/about/` | 308 → path without slash, then 200 | — | FR-022 trailing slash. A direct 200 with the same body is also conformant. |
| `/index.html`, `/triads.html` … | 308 → canonical path | — | Host "pretty URL" behavior; not linked anywhere. |
| any other path (e.g. `/nope`, `/caged`, `/triads/x`, `/Triads`) | **404** | `404.html` = home + "We could not find that page" notice | FR-010. After hydration the address is replaced with `/` (no history entry). |
| `/_app/immutable/**` | 200 | Hashed JS/CSS | Immutable. |
| `/_app/version.json` | 200 | `{"version":"X.Y.Z"}` | Emitted by SvelteKit; never polled (pollInterval 0). |

## Transport

| Request | Expected |
|---|---|
| `http://<host>/<path>` | 301 or 308, `Location: https://<host>/<path>` |
| `https://<host>/<path>` | TLS; response headers below |

## Response headers (all HTTPS responses)

| Header | Value |
|---|---|
| `Strict-Transport-Security` | `max-age=31536000; includeSubDomains` |
| `X-Content-Type-Options` | `nosniff` |
| `Referrer-Policy` | `no-referrer` |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=(), interest-cohort=()` |
| `X-Frame-Options` | `DENY` |

## Caching

| Path pattern | `Cache-Control` |
|---|---|
| `/*.html`, `/`, extensionless screen paths, `404.html` | `no-cache` (revalidate → next full load gets latest version) |
| `/_app/immutable/*` | `public, max-age=31536000, immutable` |

## Content Security Policy (in prerendered HTML `<meta http-equiv>`)

`default-src 'self'; script-src 'self' 'sha256-…'; style-src 'self' 'sha256-…'; img-src 'self' data:;
connect-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'`

- No third-party origin appears anywhere (FR-019, constitution II).
- Hashes are generated by SvelteKit `kit.csp.mode = 'hash'`.

## Runtime network behavior (browser side)

- After the `load` event, navigating among `/`, `/notes`, `/triads`, `/about` issues **zero**
  requests (single-bundle strategy; no data endpoints; no fonts; no version polling).
- No request is ever made to another origin.

## Deploy semantics

- Deploys are atomic (Cloudflare Pages switches the production alias after upload completes): a
  request during publishing receives either version N or N+1 in full, never a 5xx.
- Version N sessions keep running unchanged because they need no further requests.
