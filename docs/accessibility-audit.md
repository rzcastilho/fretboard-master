# Accessibility audit (feature 024)

Scope: WCAG 2.2 A/AA across `/`, `/notes`, `/triads`, `/caged`, `/about`, the not-found screen and a
received share link, in light and dark themes, English, Brazilian Portuguese and Spanish.

Date: 2026-10-06. Build: `pnpm build:test`. Browser: installed Google Chrome (desktop project).

## Method

| Code   | Method                                                                                                                                                                                                                                                                            |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AXE    | `e2e/a11y-audit.spec.ts`: axe-core (tags `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`) over 7 targets × 2 themes × 3 languages × the panel states each screen has (default, Legend open, description open, instrument panel open) = 102 runs. Result: **0 violations**. |
| ROLE   | Role / name / state assertions in `e2e/a11y-audit.spec.ts` (`aria-expanded`, `aria-controls`, `aria-pressed`, `aria-checked`, named groups, dialog, region, `aria-current`).                                                                                                      |
| LIVE   | Polite status assertions in `e2e/a11y-audit.spec.ts` and `e2e/view-aids.spec.ts` (debounced announcement, notices, copy confirmation, focus unchanged).                                                                                                                           |
| KBD    | `e2e/a11y-keyboard.spec.ts`: keyboard-only flows, two-tone focus ring, scroll into view.                                                                                                                                                                                          |
| CVD    | `tests/unit/a11y/palette-cvd.test.ts` and `e2e/a11y-colour.spec.ts`: ΔE00 under protan, deutan and tritan simulation; shape and label per degree.                                                                                                                                 |
| RING   | `tests/unit/a11y/focus-ring.test.ts`: two-tone ring contrast.                                                                                                                                                                                                                     |
| ZOOM   | `e2e/view-aids.spec.ts` SC-008: 320 px width and 200 % text with both panels open, no truncation, overlap or page-level horizontal scroll.                                                                                                                                        |
| MANUAL | Human check. See "Manual checklist".                                                                                                                                                                                                                                              |

## Focus-ring contrast table

Two-tone ring: outer and inner tone. WCAG 2.4.7 / 1.4.11 need 3:1 for the ring against what it sits
on. Each cell is the better of the two tones, which is what keeps the ring visible. Ratios:

| Theme | Outer / inner         | Surface      | Outer | Inner | Best  | ≥ 3:1 |
| ----- | --------------------- | ------------ | ----- | ----- | ----- | ----- |
| light | `#1a1d21` / `#ffffff` | wood         | 11.55 | 1.46  | 11.55 | yes   |
| light |                       | root fill    | 2.59  | 6.54  | 6.54  | yes   |
| light |                       | third fill   | 2.54  | 6.67  | 6.67  | yes   |
| light |                       | fifth fill   | 3.59  | 4.71  | 4.71  | yes   |
| light |                       | neutral note | 16.91 | 1.00  | 16.91 | yes   |
| dark  | `#ffffff` / `#101317` | wood         | 10.91 | 1.71  | 10.91 | yes   |
| dark  |                       | root fill    | 2.28  | 8.16  | 8.16  | yes   |
| dark  |                       | third fill   | 2.18  | 8.53  | 8.53  | yes   |
| dark  |                       | fifth fill   | 1.40  | 13.29 | 13.29 | yes   |
| dark  |                       | neutral note | 16.37 | 1.14  | 16.37 | yes   |

Before this slice the ring colour equalled the third fill (1.00:1). Octave-tone fills are asserted
in `tests/unit/a11y/focus-ring.test.ts`. Forced-colors mode maps the tones to `CanvasText` and
`Canvas`.

Fix recorded: the pre-existing `--color-focus-ring` / `--color-accent` reuse of the third colour
is **fixed** (T029). `--color-focus-ring` is the neutral outer tone, and `--color-accent` is now
light `#13466a`, dark `#c2e0f8`, no longer equal to a reserved colour.
